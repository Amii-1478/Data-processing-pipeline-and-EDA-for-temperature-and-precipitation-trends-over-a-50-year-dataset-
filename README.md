# 50-Year Climate Trend Analysis (1975–2024)

An exploratory data science project focused on modeling, analyzing, and visualizing temperature and precipitation trends across a 50-year timeline (1975–2024).

---

## 📌 Project Overview

This repository provides a clean Python data pipeline to synthesize and visualize dual-axis climate metrics. The project models long-term climate behavior through mathematical distributions:

- **Mean Annual Temperature:** Simulates a $0.03^\circ\text{C/\text{year}}$ linear warming trend from a $24.0^\circ\text{C}$ baseline with Gaussian noise ($\sigma = 0.3$).
- **Mean Annual Rainfall:** Simulates a decadal sinusoidal cycle ($\pm 100\text{ mm}$) around a $1000\text{ mm}$ baseline with Gaussian noise ($\sigma = 50$).
